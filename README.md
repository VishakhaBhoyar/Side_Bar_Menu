📸 Sidebar Menu Project (HTML + CSS)

This is a simple sidebar menu UI project designed for a photography-themed webpage. It was built using HTML and CSS as part of my learning journey through the Delta course by Apna College.

🚀 Features
- Collapsible sidebar with open/close toggle
- Icon-based navigation items (Gallery, Shortcuts, Exhibits, Events, Store, Contact, Feedback)
- Social media icons at the bottom
- Responsive layout using pure CSS
- Smooth transitions and clean UI

📁 Project Structure
CSS-mini-project
├── index.html
└── style.css

🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome (for icons)

🧠 What I Learned
- Building layout structures using HTML
- Styling and positioning sidebars with CSS
- Handling transitions and interactivity using only CSS
- Creating clean and readable code for UI components
